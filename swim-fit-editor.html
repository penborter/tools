Swim FIT editor

Fix a pool swim recorded by a Garmin watch: relabel lengths with the wrong stroke, split a length where a turn was missed, or merge lengths that were double-counted. Everything happens in your browser, and you get back a corrected .fit file.

Drop a .fit file here or click to select

Garmin Connect → activity → ⚙ → Export Original (unzip it first)

Each column is one length; its height is the length time. Click to select, click more lengths to add them, Shift-click to select a run. ← → move, Esc clears.

Changes

    Re-uploading: Garmin Connect and Strava reject a file that duplicates an existing activity, so delete the original activity before importing the edited file.

    Interval and activity totals (distance, length counts, pace, SWOLF, strokes per length) are recalculated after each edit. Heart rate, calories and everything else in the file are left untouched.
